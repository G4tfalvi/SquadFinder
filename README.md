# SquadFinder

A web-based platform designed to help players find teammates, connect with other users, and organize gaming sessions.

**Repository:** [G4tfalvi/SquadFinder](https://github.com/G4tfalvi/SquadFinder)

## Overview

SquadFinder is a full-stack web development project focused on connecting players through a shared platform.

The application includes user accounts, player profiles, social features, and tools for finding other players and organizing gaming sessions.

## Features

- **User Authentication** – User registration and login.
- **Player Profiles** – Individual user profiles.
- **Friend System** – Connect and interact with other users.
- **Player Discovery** – Search for other players.
- **Lobby System** – Create or join gaming sessions.
- **Messaging** – Communicate with other users.

## Technologies

- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose
- HTML / CSS (where used in the frontend)

## Project Structure

The project is organized into separate areas for application functionality, including:

- Authentication and login
- User models
- Profile management
- Static assets
- Server-side application logic

## Purpose

The goal of this project was to build a functional web application while gaining practical experience with backend development, databases, user authentication, and full-stack application architecture.

## Status

Personal development project. Features and implementation may continue to evolve.
